1. Insertion Sort

Time Complexity
Best Case O(n)

Occurs when the input array is already sorted. The outer loop runs $n-1$ times while the inner while-condition fails on first comparison ($1$ check per element).

Worst Case O(n²)

Occurs when the input array is sorted in reverse order. Every element must be shifted past all previously sorted elements ($n(n-1)/2$ shifts).

2. Binary Search

O(log n) Complexity

Searches for a student by Name. Requires array to be sorted by Name first using Insertion Sort, then iteratively halves the search interval by comparing middle element pointers.
